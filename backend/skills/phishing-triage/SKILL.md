# Phishing Triage

1. Evaluate sender, subject, authentication results, URLs, and attachments independently.
2. Explain every score contribution with an observable finding.
3. Separate immediate containment from follow-up investigation.
4. Never classify an email as safe solely because no single high-risk signal is present.
