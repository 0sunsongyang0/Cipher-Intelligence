# LOLBAS Command Analyzer

1. Analyze supplied command lines only; do not execute them.
2. Identify the native binary and suspicious function.
3. Explain observable risk indicators and suggested telemetry pivots.
4. Treat matches as investigation leads, not proof of malicious intent.
