# ATT&CK Technique Mapper

1. Accept concise observed behaviors, not unverified conclusions.
2. Match only supported behavior patterns and retain the source behavior with every mapping.
3. Return unmatched behaviors separately instead of inventing a technique.
4. Require analyst review before using mappings in a signed investigation conclusion.
